# OpenGL Testing Suite

This module provides comprehensive testing for OpenGL functions across different versions.

## Overview

The OpenGL testing suite is designed to:
- Test OpenGL functions in groups (individual function testing is not feasible)
- Target specific OpenGL versions with version-appropriate functions
- Be cross-compilation friendly (tested with `just arm`)
- Provide visual output for verification
- Generate automatic documentation of function coverage

## Architecture

Each test is self-contained and targets a specific OpenGL version:

- **GL 1.1 Immediate Mode** - Tests legacy immediate mode rendering
- **GL 1.5 VBO** - Tests Vertex Buffer Objects
- **GL 2.0 Shaders** - Tests programmable shaders
- **GL 3.3 VAO** - Tests Vertex Array Objects and modern pipeline

## Running Tests

Enable the `gpu` feature to compile OpenGL tests:

```bash
cargo test --features gpu
```

Or run via the CLI:

```bash
cargo run --features gpu -- --gpu
```

## Adding New Tests

To add a new test:

1. Create a new file in `tests/` directory (e.g., `gl40_compute.rs`)
2. Add special comments with metadata:
   ```rust
   //! GL_VERSION: 4.0
   //! GL_FUNCTIONS: glDispatchCompute, glMemoryBarrier, ...
   ```
3. Implement the `GLTest` trait
4. Register the test in `tests/mod.rs`
5. Run `python3 scripts/generate_gl_table.py` to update the table

## Cross-Compilation

Tests are designed to be cross-compilation friendly:

```bash
just arm  # Test ARM 32-bit cross-compilation
```

## Dependencies

- `glutin` - OpenGL context creation
- `gl` - OpenGL function bindings
- `glow` - Safe OpenGL wrapper (optional)

## Notes

- The `gpu` feature in Cargo controls whether this module is compiled
- Tests use headless contexts where possible
- Each test should be self-contained and use version-appropriate functions
- Visual output is provided for verification purposes
