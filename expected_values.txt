# Expected values for generated test assertions.
# Format: test_name - rust_expr
#
# For SIMD array returns (e.g. __m128 → [f32; 4]):
#   test_mm_add_ps - [2.0f32, 4.0f32, 6.0f32, 8.0f32]
#
# For integer returns:
#   test_mm_movemask_epi8 - 0i32
#
# Notes:
# - The value is pasted verbatim into the generated Rust assertion.
# - Omitting a function uses the default (zeros).
# - NaN-returning functions cannot be compared with check_array_equality;
#   leave them out (they will use the zeroed default, which will likely fail
#   at runtime — add a custom override here with a valid expected value).
#
# Example entries:
# test_mm_cmpngt_ps - [0xFFFFFFFFu32 as f32; 4]
# test_mm_comile_ss - 1
